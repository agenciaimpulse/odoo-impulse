# odoo-impulse
Este repositório foi criado para centralizar os módulos Odoo desenvolvidos pela Agência Impulse. Ele funciona como um hub modular, onde cada subpasta representa um projeto ou funcionalidade personalizada — facilitando a organização, o versionamento e a manutenção do código. A estrutura é simples e intuitiva: cada módulo personalizado fica em seu próprio diretório, permitindo que a equipe adicione novos recursos, atualize módulos existentes ou colabore em melhorias com mais agilidade.

O objetivo é manter um ambiente limpo, reutilizável e acessível para todos os envolvidos no desenvolvimento de soluções Odoo da agência. Essa abordagem modular torna mais fácil isolar funcionalidades, gerenciar dependências e garantir maior controle sobre a evolução dos projetos.

Ideal para desenvolvedores da equipe e colaboradores externos, este repositório é a base organizada para todos os projetos Odoo da Impulse — promovendo eficiência, clareza e colaboração.
