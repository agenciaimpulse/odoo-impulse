# ⚓ Odoo Addons — Impulse Ops

Community addons for **Odoo Community Edition**, developed and maintained by **Impulse Ops**.

This repository centralizes reusable Odoo addons developed by Impulse Ops and organizes them by **Odoo version**, following the branch-based model commonly used in the Odoo ecosystem.

## 📦 Available versions

| Odoo version | Branch                                                        | Status    |
| ------------ | ------------------------------------------------------------- | --------- |
| Odoo 18      | [`18.0`](https://github.com/impulseops/odoo-addons/tree/18.0) | Available |
| Odoo 19      | [`19.0`](https://github.com/impulseops/odoo-addons/tree/19.0) | Available |

Each version has its own branch and contains only addons compatible with that Odoo release.

## 🧩 Addons

### Odoo 19

The `19.0` branch currently includes:

* [`odoo_dbfilter_header`](https://github.com/impulseops/odoo-addons/tree/19.0/odoo_dbfilter_header) — selects an Odoo database based on the request hostname, using a normalized hostname-to-database naming convention.

See the [Odoo 19 addons index](https://github.com/impulseops/odoo-addons/tree/19.0).
